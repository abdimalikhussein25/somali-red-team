| Platform | Best for | Cost |

| [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) | Run locally, modern web app bugs | Free |
| [CTFtime](https://ctftime.org) | Calendar of live CTFs to play as a team | Free |

**Low bandwidth?** OWASP Juice Shop and VulnHub VMs run fully offline once downloaded — good for areas with unreliable internet.
